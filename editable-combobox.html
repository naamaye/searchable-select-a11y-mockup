    What this fixes vs the previous pattern

    • No nested search in the list — one typing surface (the combobox). Removes dual-focus / wrong-role risk.
    • Visible label “Assignee” — placeholder is not the only name (SC 3.3.2).
    • Clear has aria-label + 28×28 target — icon-only control is named and ≥24×24 (SC 4.1.2, 2.5.8).
    • Focus on trigger while open; active option styled — visible focus + option highlight not color-only (SC 2.4.7, 1.4.1).
    • Selected value ≠ placeholder styling — empty vs filled are distinguishable.
    • APG keys — arrows, Enter, Esc; filter by typing in the field.
    • Empty results — “No results” text announced via live region when filter matches nothing.
