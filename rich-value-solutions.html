      Why this works for icons

      The collapsed field is not limited to an input string. Avatar is real DOM inside the button. Name comes from label + value text (“Assignee, Julia Martinez”), so AT is never “blank.”

      Trade-off: users don’t type in the same surface as the selected value — they open first, then filter. Matches nested-search UX, with correct focus.
